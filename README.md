# 🚀 Beyond Earth: Junior Astronaut Trainer
🎮 Play it live: https://رابطكم.streamlit.app](https://beyond-earth.streamlit.app/



لعبة ويب يختار فيها الطفل كوكب جديد للبشر، وكل الأرقام فيها من ناسا.

## 📁 الملفات
| الملف | وش فيه |
|---|---|
| `app.py` | يشغّل اللعبة ويعطيها داتا ناسا |
| `game.html` | شاشة اللعبة: اللوبي والكواكب والمراحل والإعدادات |
| `assets/earth_intro.jpg` | رسمة شاشة البداية |
| `game_logic.py` | الحسابات وجلب داتا ناسا والنصوص  |
| `requirements.txt` | المكتبات المطلوبة |

## ▶️ التشغيل على اللابتوب (الأفضل للديمو)
1. تأكد إن Python مثبت (3.9 أو أحدث)
2. افتح Terminal أو CMD داخل هذا المجلد
3. ثبت المكتبات:
   ```
   pip install -r requirements.txt
   ```
4. شغل اللعبة:
   ```
   streamlit run app.py
   ```
5. بتنفتح لك في المتصفح على `http://localhost:8501` 🎉


## 🎮 اللعبة
1. **المقدمة:** الأرض تحترق (رسمتكم مع دخان وشرار)
2. **لوبي المكوك:** نافذة تطل على الكواكب، وتنبيه طقس فضاء حقيقي من ناسا في الكونسول
3. **اضغط على كوكب:** تطلع نافذة معلوماته ← "ادخل الكوكب"
4. **دراسة الكوكب:** صخري = اختبار نط وجاذبية + فحص · غازي = تطفو وتشغل الدفع · الزهرة = مسبار قبل ما يذوب
5. **التقرير + مهمتك الأرضية** 🌍
6. **القرار الكبير** (بعد 3 كواكب): المفاجأة إن أنسب كوكب هو الأرض
- ⚙️ الإعدادات: الوضع الليلي/النهاري، حجم الخط، الحركات، أرقام ناسا، مسح التقدم

## 📊 مصادر الداتا (كلها ناسا)
- NASA Exoplanet Archive: الكواكب البعيدة (تنجاب مباشرة)
- NASA Planetary Fact Sheet: القمر والمريخ والزهرة
- NASA DONKI (ccmc.gsfc.nasa.gov/DONKI-API): الانفجارات الشمسية
- مقياس الشبه بالأرض (ESI): نحسبه بمعادلة Schulze-Makuch et al. 2011
